# Все чаты — распаковано и разложено

Архив `все чаты.part1.rar` + `все чаты.part2.rar` (многотомный RAR5) распакован:
**259 диалогов → 518 файлов → 98 МБ**. Все файлы сверены с содержимым архива (размер + SHA-256, расхождений нет), после чего исходные `.rar` удалены из рабочего дерева (в истории git они остались).

Это экспорт чатов из [Arena.ai](https://arena.ai) (Arena Chat Exporter v2.4.0, `json+txt`), сделанный 2026-10-09.

## Структура

```
chats/
  <тема>[/<подтема>]/<тип>/<год-месяц>/<NNN>-<название-диалога>/
      chat.json   ← сырой экспорт (все поля, модели, служебные данные)
      chat.txt    ← читаемая расшифровка диалога
```

- **`<тема>[/<подтема>]`** — тематика, определённая по ключевым словам в заголовке и первом сообщении (у CK2 есть подтемы, см. таблицу).
- **`<тип>`** — `agentic` (66 шт., режим агента) или `chat` (193 шт., обычный чат/слепое сравнение моделей).
- **`<год-месяц>`** — дата создания диалога (2025-07 … 2026-10).
- **`<NNN>`** — сквозной номер по дате (001…259), совпадает с номером в `chats/index.csv`.

Примеры:
```
chats/ck2-paradox/mods-data/chat/2026-02/086-copy-chars-with-id-ending-with-and-in-two-separate-lists/
chats/ck2-paradox/aar-narrative/chat/2026-02/055-narrate-worlds-pov-seeing-one-peculiar-rising-dynasty/
chats/skyrim/agentic/2026-09/206-i-want-skyrim-rp-i-was-a-regular-teenager-really-liked-to-play/
```

## Файлы-указатели

- `chats/index.csv` — таблица всех 259 диалогов: дата, тип, тема, подтема, язык, число сообщений, модели, id, **оригинальные имена файлов**, путь, ссылка на чат (UTF-8 с BOM — открывается в Excel).
- `chats/index.json` — то же самое в JSON для скриптов.
- `chats/INDEX.md` — список диалогов по темам со ссылками на папки.
- `chats/manifest.json` — родной манифест экспортёра (что выгружалось и с какими предупреждениями).

## Замечания

- Сортировка автоматическая и приблизительная: темы присвоены по ключевым словам. Если что-то попало не туда — скажите, перекину.
- Файлы внутри папок диалогов переименованы в `chat.json` / `chat.txt`; оригинальные имена сохранены в `chats/index.csv` (колонки `originalJson`, `originalTxt`).
- Вложения (картинки/файлы) экспортёр не скачивал — в JSON только ссылки, часть из них может протухнуть.
- Архив был многотомным RAR5; всё распаковано и проверено, тома больше не нужны.
