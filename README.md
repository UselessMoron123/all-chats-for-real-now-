# Все чаты — распаковано и разложено

Архив `все чаты.part1.rar` + `все чаты.part2.rar` (многотомный RAR5, 17 МБ) распакован:
**259 диалогов → 518 файлов → 98 МБ**, все файлы проверены (размер + SHA-256 совпадают с содержимым архива, ошибок нет).

Это экспорт чатов из [Arena.ai](https://arena.ai) (Arena Chat Exporter v2.4.0, `json+txt`), сделанный 2026-10-09.

## Структура

```
chats/
  <тема>/<тип>/<год-месяц>/<NNN>-<название-диалога>/
      chat.json   ← сырой экспорт (все поля, вложения-ссылки, модели)
      chat.txt    ← читаемая расшифровка диалога
```

- **`<тема>`** — приблизительная тематика (определена по ключевым словам, см. ниже).
- **`<тип>`** — `agentic` (66 шт., режим агента) или `chat` (193 шт., обычный чат/слепое сравнение моделей).
- **`<год-месяц>`** — дата создания диалога (2025-07 … 2026-10).
- **`<NNN>`** — сквозной номер по дате (001…259), совпадает с номером в `chats/index.csv`.

Пример: `chats/ck2-paradox/chat/2026-02/066-narrate-worlds-pov-seeing-one-peculiar-rising-dynasty/`

## Файлы-указатели

- `chats/index.csv` — таблица всех 259 диалогов: дата, тип, тема, язык, число сообщений, модели, id, оригинальные имена файлов, путь, ссылка на чат (UTF-8 с BOM — открывается в Excel).
- `chats/index.json` — то же самое в JSON (для скриптов).
- `chats/INDEX.md` — список диалогов по темам со ссылками на папки.
- `chats/manifest.json` — родной манифест экспортёра (что выгружалось, с какими предупреждениями).

## Замечания

- Исходные `все чаты.part1.rar` / `part2.rar` оставлены в корне репозитория — после проверки распаковки они больше не нужны, могу удалить.
- Файлы внутри папок диалогов переименованы в `chat.json` / `chat.txt`; **оригинальные имена сохранены** в `chats/index.csv` (колонки `originalJson`, `originalTxt`).
- Сортировка первая и приблизительная: темы присвоены по ключевым словам в заголовке и первом сообщении. Если где-то промахнулся — скажите, перекину папки (или можно перестроить дерево по другому принципу: только по дате, по языку, по модели, «agentic/chat» сверху и т.п.).
- Вложения (картинки/файлы) экспортёр не скачивал — в JSON только ссылки, часть из них может протухнуть.
