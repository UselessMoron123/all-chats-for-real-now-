# Using:
- Must have full administrator rights: Computer Configuration - Windows Settings - Security Settings - Local Policies - Security Options - User Account Control: All Administrators Run in Approval Mode - Disabled.

- The image must be mounted.
- You need any RAM disk with the letter Z (it's just the last letter of the alphabet), 11500MB in size with which DISM (SoftPerfect RAM Disk and analogues) can work.
- Unpack the scripts, install.wim and boot.wim files (from the source folder of the .iso file) to the root of the RAM disk.
- Run Clear.bat and wait for the window to close.

- The image is ready.

## Что такое Windows by SLMP

**SLMP** (он же **Mitradis** на GitHub, также известен как *intellect*) — программист, ранее прославившийся лорными модпаками для Skyrim (SLMP = Simple Lore Mods Pack), который делал одни из самых качественных кастомных сборок **Windows 10 и Windows 11**.

Отличия его сборок от других:

- **Полностью открытый DISM-скрипт** — автор публиковал весь код создания сборки от начала до конца (уникальный случай для ру-нета). Никаких скрытых «улучшений» — всё, что делает скрипт, видно в блокноте.

- **Минимальная нагрузка на SSD/RAM/CPU** — не за счёт вырезания системных файлов, а за счёт отключения десятков служб, задач планировщика, журналов, телеметрии и рекламы.
- Классический Пуск (StartIsBack / StartAllBack / Start11), удалён Магазин и мусорные приложения, отключён Защитник (нужен сторонний антивирус).

## Инструкция автора: как сделать сборку самому

(из README репозиториев, русская часть; для Win 11 отличия отмечены)

### Подготовка

1. **Полные права администратора**: Win+R → `gpedit.msc` → Конфигурация компьютера — Конфигурация Windows — Параметры безопасности — Локальные политики — Параметры безопасности → **«Контроль учетных записей: все администраторы работают в режиме одобрения» — Отключено** (UAC на ноль).
2. **Оригинальный образ**: нужен строго тот ISO, редакция и контрольные суммы которого указаны в описании релиза скрипта (для старых версий: Win10 22H2 build 19045.x, Win11 22H2/23H2 build 22621/22631, редакция Professional). Образ должен быть **смонтирован** (открыт в системе).
3. **RAM-диск с буквой `Z:`** размером **11500 МБ для Win10 / 12500 МБ для Win11** — любой, с которым умеет работать DISM (например, SoftPerfect RAM Disk). Буква именно Z.

### Сборка

4. Распаковать **скрипты** и файлы **`install.wim` и `boot.wim`** (из папки `sources` смонтированного .iso) **в корень RAM-диска Z:**.
5. *Только для Windows 11:* скачать **Start11 версии 1.24** и положить в `Z:\PostClear` под именем `Start11.exe` (скрипты рассчитаны на репак от diakov.net для тихой установки). *(Вариант команды Revision — со StartAllBack вместо Start11.)*
6. Запустить **`Clear.bat`** (в версиях 2024–2025 — **`_Clear.bat`**) и дождаться, пока окно само закроется. Скрипт сам: монтирует boot.wim и ставит обход проверок TPM/CPU/RAM/SecureBoot, монтирует install.wim, удаляет предустановленные пакеты и возможности, применяет пакет групповых политик через LGPO, отключает службы, задачи планировщика, журнал событий, Защитник, обновления, ставит заглушки (upfc.exe), заменяет калькулятор, подкладывает файлы первичной настройки (PostClear) и сжимает образ.
7. Открыть **`Clear.log`** на диске Z и поиском проверить отсутствие ошибок по словам: **«опе», «оши», «нет», «не », «отк»**.
8. Запустить CMD и выполнить **первую команду из `_readme.txt`** — конвертацию и сжатие образа:

   ```
   dism /export-image /sourceimagefile:Z:\install.wim /sourceindex:1 /destinationimagefile:Z:\install.esd /compress:recovery
   ```

9. С помощью **UltraISO** (или аналога): удалить в .iso файл `sources\install.wim` и добавить получившиеся **`install.esd`** и **`boot.wim`**.
10. **Образ готов.** Записать на флешку (Rufus/UltraISO/Ventoy).

### Установка — важные правила

- Устанавливать **строго при выключенном Интернете**. Сеть включать только **после двух автоматических перезагрузок** системы (должен отработать PostClear-скрипт первого входа).
- Не включать и не запускать «Центр обновления» в службах — это ломает систему вплоть до переустановки.
- Магазина нет — плиточные приложения ставятся без Store (есть известные способы/сервисы).
- Защитник отключён — поставьте сторонний антивирус, если нужен.
- Активация штатная не затронута — активируйте как обычно (HWID/MAS).
- Бонус: `WinTool.exe -setup=` (для Win10) / `WinTool.exe -setup=?` (для Win11) — показать все применяемые опции твикера и их номера-маски.

## Что именно делает скрипт (кратко)

- Полное отключение Обновлений и «резервных» служб (установка автономных MSU-пакетов при этом остаётся возможной).
- Полное отключение Защитника и смежных служб, SmartScreen, обновлений Edge.
- Удаление OneDrive, предустановленных appx-пакетов, лишних «возможностей» и редакций (остаётся Pro).
- Десятки отключённых служб и задач планировщика, отключение журналов событий (меньше записи на SSD).
- Пакет групповых политик (телеметрия, реклама, советы, Кортана, облако, отчёты об ошибках и т.д. — полный список в `_readme.txt`).
- Возврат классических Блокнота/Paint/Фотографий/Диспетчера задач/Калькулятора (в Win 11), отключение окна переключения языков, банера рекламы в Параметрах.
- Обход системных требований при установке (TPM/RAM/CPU/SecureBoot) — в boot.wim.
- Всё стандартными средствами: DISM, CMD/PowerShell, реестр — системные файлы не модифицируются.

## Часть 0. Как это устроено (30 секунд теории)

ISO-образ Windows = `boot.wim` (среда установки) + `install.wim` (сама система, один или несколько выпусков: Home/Pro/...).

`install.wim` можно **смонтировать в папку** как обычный каталог (`dism /mount-image`), и дальше:

- **удалять предустановленные приложения** (Provisioned AppX: Кортана, Xbox, Погода, Магазин...),
- **удалять/отключать компоненты** (FOD Capabilities и Features),
- **править реестр системы** через `reg load` (грузим кусты `SOFTWARE`, `SYSTEM`, `NTUSER.DAT` офлайн-системы как ветки своего реестра и импортируем .reg),
- **применять групповые политики** (LGPO.exe + файлы .pol),
- подкладывать/заменять файлы (answer-file `unattend.xml`, классический калькулятор, заглушки),
- затем **размонтировать с сохранением** (`/commit`) и **сжать** (`/export-image /compress:recovery` → install.esd).

Всё это ровно то, что делает скрипт SLMP — просто у него это вылизано годами и оформлено в один `Clear.bat`.

- размонтирование с сохранением (`/commit`).

**`PostClear\`** (срабатывает при **первом входе** в установленную систему):
- `PostClearM.bat` + **LGPO.exe** применяют пакет групповых политик (файлы `GPm.pol/GPM.pol` — машины, `GPu.pol/GPU.pol` — пользователя): полный список — в `_readme.txt` (Defender, SmartScreen, OneDrive, телеметрия, Магазин, Кортана/поиск в интернете, новости и интересы, отчёты об ошибках, синхронизация, диагностика и десятки других = Вкл/Откл);
- установка **Classic Shell** (Win10) / **Start11** (Win11) — классический/удобный Пуск;
- Win11: тикер **WinTool.exe** (сам тоже располагает службами/файерволом/Edge-обновлениями), HelpTool, справка WinHelp.html;
- очистка, перезапуск проводника, **перезагрузка** (поэтому «2 автоперезагрузки»).

### Как кастомизировать под себя

Скрипты — обычный текст, открывайте Блокнотом/VS Code:

- **Хотите оставить Магазин / Фото / Xbox?** Удалите соответствующую строку из массива `$apps` в `Clear.ps1` (например `"Microsoft.WindowsStore_11910.1002.513.0_neutral_~_8wekyb3d8bbwe",`). ⚠️ Магазин всё равно не заработает, пока заблокирован ЦО — это парная логика автора.
- **Не хотите отключать Защитник?** Уберите из `Clear.reg` блоки `WinDefend/WdNisSvc/Sense` и из `_readme.txt`-политик (GPM.pol/GPU.pol применяется LGPO — удаляйте PostClear-файлы или правьте .pol в LGPO-редакторе), и уберите `Windows-Defender-Default-Definitions` из ps1.
- **Не трогать UAC / Meltdown-патчи** — удалите эти блоки из `Clear.reg`.
- **Другой калькулятор / свой набор ярлыков** — правьте секции `Calc`/`Shortcuts` в `Clear.bat`.
- **Свой список служб/задач** — дописывайте `reg add ... Services\Имя /v Start /d 4` в Clear.reg и задачи в `schtasks`-стиле через `PostClearM.bat`.

### Известные грабли

- Списки appx с точными версиями рассчитаны на конкретный билд — для сильно другого ISO часть `remove-provisionedappxpackage` вернёт ошибку в логе (не критично, остальные применятся). Надёжнее брать тот билд, под который писался скрипт, или обновить версии пакетов командой из `_readme.txt`: `dism /image:Z:\Install /get-provisionedappxpackages > Z:\list1.txt` (сначала смонтировав: `dism /mount-image /imagefile:Z:\install.wim /index:1 /mountdir:Z:\Install`).
- Сначала смонтировать вручную не забудьте — `Clear.bat` монтирует сам, но ручные команды из `_readme.txt` («Информационные команды») предполагают уже смонтированный `Z:\Install`.
- Win11: если скрипт ругается на Start11.exe — файл не положили в `Z:\PostClear`.
- Антивирус на ПК может ругаться на `upfc.exe`-заглушку/LGPO — это ложные срабатывания (файлы открытым текстом видны в репо).

## Часть 2. Универсальный DIY-рецепт (без чужих скриптов, на обычном диске)

Тот же принцип, всё своими командами. Работает для Win10/11 любого билда, ничего специально подготавливать не надо (RAM-диск опционален).

### Шаг 1. Подготовка

```
mkdir C:\WIM\mount C:\WIM\sxs
```
Скачайте оригинальный ISO (Media Creation Tool / MSDN/VLSC образ «Business editions» = сразу Pro/VL). Смонтируйте ISO (пусть будет диск `E:`). Скопируйте `E:\sources\install.wim` → `C:\WIM\`.

### Шаг 2. Посмотреть, что внутри

```
dism /get-imageinfo /imagefile:C:\WIM\install.wim
```
Найдите индекс нужной редакции (например, «Windows 10 Pro» = индекс 6).

### Шаг 3. Оставить только Pro (убрать лишние редакции)

Либо удалите ненужные индексы (`dism /delete-image /imagefile:C:\WIM\install.wim /index:N`), либо сразу экспортируйте один индекс в новый wim:
```
dism /export-image /sourceimagefile:C:\WIM\install.wim /sourceindex:6 /destinationimagefile:C:\WIM\install_pro.wim /compress:max
```

### Шаг 4. Смонтировать систему

```
dism /mount-image /imagefile:C:\WIM\install_pro.wim /index:1 /mountdir:C:\WIM\mount
```

### Шаг 5. Вычистить мусор

Посмотреть списки (сохраняются в файлы — удобно гуглить каждый пакет):
```
dism /image:C:\WIM\mount /get-provisionedappxpackages > C:\WIM\apps.txt
dism /image:C:\WIM\mount /get-capabilities > C:\WIM\caps.txt
dism /image:C:\WIM\mount /get-features > C:\WIM\feats.txt
```

Удалить предустановленные приложения (примеры — берите имена из apps.txt):
```
dism /image:C:\WIM\mount /remove-provisionedappxpackage /packagename:Microsoft.BingWeather_...
dism /image:C:\WIM\mount /remove-provisionedappxpackage /packagename:Microsoft.549981C3F5F10_...   (Кортана)
dism /image:C:\WIM\mount /remove-provisionedappxpackage /packagename:Microsoft.XboxApp_...
```
⚠️ Не удаляйте `Microsoft.WindowsStore`, если оставляете рабочий ЦО, и `Microsoft.VCLibs/.NET Native/WindowsStore`-рантаймы, если ставите UWP-приложения.

Удалить Capabilities (FOD):
```
dism /image:C:\WIM\mount /remove-capability /capabilityname:App.StepsRecorder~~~~0.0.1.0
dism /image:C:\WIM\mount /remove-capability /capabilityname:App.Support.QuickAssist~~~~0.0.1.0
dism /image:C:\WIM\mount /remove-capability /capabilityname:Hello.Face.18967~~~~0.0.1.0
```

Отключить ненужные компоненты / включить .NET 3.5 (исходник — `E:\sources\sxs`):
```
dism /image:C:\WIM\mount /enable-feature /featurename:NetFx3 /all /source:E:\sources\sxs /limitaccess
dism /image:C:\WIM\mount /disable-feature /featurename:WindowsMediaPlayer
```

### Шаг 6. Реестр офлайн (твики)

```
reg load HKLM\WIM_SOFT C:\WIM\mount\Windows\System32\config\SOFTWARE
reg load HKLM\WIM_SYS  C:\WIM\mount\Windows\System32\config\SYSTEM
reg load HKLM\WIM_DEF  C:\WIM\mount\Users\Default\NTUSER.DAT
```
Импортируйте свой .reg (пути внутри должны указывать на WIM_SOFT/WIM_SYS/WIM_DEF). Рабочие примеры из арсенала SLMP:

```reg
; отключить Защитник
[HKLM\WIM_SYS\ControlSet001\Services\WdNisSvc] "Start"=dword:00000004
[HKLM\WIM_SYS\ControlSet001\Services\WinDefend] "Start"=dword:00000004
[HKLM\WIM_SYS\ControlSet001\Services\Sense] "Start"=dword:00000004
; отключить Medic Центра обновлений
[HKLM\WIM_SYS\ControlSet001\Services\WaaSMedicSvc] "Start"=dword:00000004
; отключить UAC
[HKLM\WIM_SOFT\Microsoft\Windows\CurrentVersion\Policies\System]
"EnableLUA"=dword:00000000
"ConsentPromptBehaviorAdmin"=dword:00000000
; отключить советы/рекламу/контент облака
[HKLM\WIM_SOFT\Policies\Microsoft\Windows\CloudContent]
"DisableSoftLanding"=dword:00000001
"DisableWindowsConsumerFeatures"=dword:00000001
; автозапуск своего скрипта при первом входе
[HKLM\WIM_DEF\SOFTWARE\Microsoft\Windows\CurrentVersion\Run]
"PostSetup"="C:\\ProgramData\\MySetup\\setup.bat"
```
Выгрузить кусты:
```
reg unload HKLM\WIM_SOFT
reg unload HKLM\WIM_SYS
reg unload HKLM\WIM_DEF
```

### Шаг 7. Групповые политики (опционально, как у автора)

Возьмите **LGPO.exe** (из Security Compliance Toolkit Microsoft): настройте политики на эталонной машине, сохраните бэкап (`LGPO.exe /b C:\backup`) и примените к смонтированному образу: `LGPO.exe /g C:\backup\{GUID}` — либо просто положите свой твикер/файлы в образ и запускайте при первом входе (Run-ключ из шага 6).

### Шаг 8. Ответный файл (OOBE)

Положите `unattend.xml` в `C:\WIM\mount\Windows\Panther\` (пример — в `slmp/Windows-10-DISM-Scripts_2022/unattend.xml`: `ProtectYourPC=3` и скрытие Wi-Fi-шага).

### Шаг 9. Чистка и закрытие образа

```
dism /image:C:\WIM\mount /cleanup-image /startcomponentcleanup
dism /unmount-image /mountdir:C:\WIM\mount /commit
```

### Шаг 10. Сжать и собрать ISO

```
dism /export-image /sourceimagefile:C:\WIM\install_pro.wim /sourceindex:1 /destinationimagefile:C:\WIM\install.esd /compress:recovery
```
Положите `install.esd` (вместо install.wim) обратно в распакованную копию ISO и соберите образ:
- **UltraISO**: открыть оригинал ISO → заменить файлы → сохранить; или
- **oscdimg** (из Windows ADK): `oscdimg -m -o -u2 -udfver102 -bootdata:2#p0,e,bE:\boot\etfsboot.com#pEF,e,bE:\efi\microsoft\boot\efisys.bin C:\WIM\iso C:\WIM\Windows10_custom.iso`

### Шаг 11. Win11: обход TPM/CPU/RAM/SecureBoot (если надо)

Грузится не всегда — тогда правится `boot.wim` (индекс 2):
```
dism /mount-image /imagefile:C:\WIM\boot.wim /index:2 /mountdir:C:\WIM\bootmount
reg load HKLM\WIM_BOOT C:\WIM\bootmount\Windows\System32\config\SYSTEM
reg add HKLM\WIM_BOOT\Setup\LabConfig /v BypassTPMCheck /t REG_DWORD /d 1
reg add HKLM\WIM_BOOT\Setup\LabConfig /v BypassCPUCheck /t REG_DWORD /d 1
reg add HKLM\WIM_BOOT\Setup\LabConfig /v BypassRAMCheck /t REG_DWORD /d 1
reg add HKLM\WIM_BOOT\Setup\LabConfig /v BypassSecureBootCheck /t REG_DWORD /d 1
reg unload HKLM\WIM_BOOT
dism /unmount-image /mountdir:C:\WIM\bootmount /commit
```
(именно это автоматом делает `_Clear.bat` из пакета Win11). Либо на живой установке — `Shift+F10` → `regedit` те же ключи в `HKLM\SYSTEM\Setup\LabConfig`.

### Шаг 12. Тест

Обязательно прогоните образ в виртуалке (VirtualBox/Hyper-V) до установки на живой ПК. Установка — без интернета до конца OOBE (если делали автозапуск первого входа — до пары перезагрузок).

## Альтернатива: «живой» способ через режим аудита

Классика вместо offline-правок: ставите чистую Windows в виртуалку → `Ctrl+Shift+F3` (вход в **режим аудита**) → удаляете программы через «Приложения и возможности», ставите нужное, твикаете систему → `sysprep /generalize /oobe /shutdown` → загружаетесь с WinPE и снимаете образ (`dism /capture-image` или DISM++). Минусы: дольше, тяжелее, риск остатков; плюсы: не надо разбираться в офлайн-кустах. Скрипт SLMP принципиально делает offline — образ остаётся «чистым», без мусора от установки.

## Шпаргалка: что чем удалять

| Что убрать | Чем | Команда/где |
|---|---|---|
| Магазин, Xbox, Кортана, Погода и пр. UWP | Provisioned AppX | `dism /image:... /remove-provisionedappxpackage /packagename:...` |
| Мелкие FOD (Quick Assist, Hello, MathRec) | Capabilities | `dism /image:... /remove-capability /capabilityname:...` |
| WordPad, MediaPlayer, IE, SMB1... | Features | `dism /image:... /disable-feature /featurename:...` |
| Службы (Defender, WaaSMedic...) | Реестр офлайн | `reg load` → `Services\<имя>\Start=4` |
| Телеметрия/реклама/Кортана | Групповые политики | LGPO.exe + .pol (или `Policies`-ветки реестра) |
| Edge-обновления, OneDrive | Файлы + реестр | удаление каталогов + веток Uninstall/Run |
| Обход TPM/CPU/RAM (Win11) | boot.wim | `Setup\LabConfig` DWORD=1 |
| Размер образа | export-image | `/compress:recovery` → install.esd |

⚠️ **Три правила, чтобы не получить «кирпич»**: (1) не удаляйте файлы из `WinSxS` наугад и не отключайте обслуживание образов совсем; (2) всегда `/commit` только после проверки лога, а эксперименты — через `/discard`; (3) держите оригинальный `install.wim` нетронутым — работаете с копией.

## Суть метода (одинаково и у автора, и DIY)
Оригинальный `install.wim` из ISO **монтируется в папку** и чистится офлайн, без установки системы:
- `dism /remove-provisionedappxpackage` — удаление UWP-мусора (Кортана, Xbox, Погода, Магазин...)
- `dism /remove-capability` / `/disable-feature` — мелкие компоненты
- `reg load` кустов `SOFTWARE/SYSTEM/NTUSER.DAT` → импорт твиков (службы, UAC, Защитник, телеметрия)
- LGPO.exe + .pol — пакет групповых политик
- `/commit` → сжатие в `install.esd` → запаковка обратно в ISO

## Способ 1 — как автор
Скрипты уже лежат у вас в `slmp/`. Порядок: RAM-диск **Z:** (~12 ГБ) → UAC в ноль → скрипты + `install.wim`/`boot.wim` из ISO в корень Z: → запуск `Clear.bat` → проверка `Clear.log` → DISM-команда конвертации в ESD (она же в `_readme.txt`) → UltraISO для пересборки ISO. Установка — **строго без интернета** до двух автоперезагрузок, ЦО не включать никогда.

## Способ 2 — руками под себя
В гайде все команды копипастой: от `dism /mount-image` до сборки ISO через oscdimg/UltraISO, включая обход TPM для Win11 через правку `boot.wim` и таблицу «что чем удалять».

Из интересного, что я нашёл внутри скриптов автора: он отключает Meltdown/Spectre-патчи (плюс к FPS), глушит журнал событий целиком (меньше записи на SSD), подменяет `upfc.exe` пустышкой, ставит заглушку в «Медик» Центра обновлений и возвращает классический калькулятор и «Просмотр фотографий».

Весь процесс легко кастомизируется — списки приложений в `Clear.ps1` редактируются Блокнотом (хотите оставить Фото или Xbox — просто удалите строку). Если что-то пойдёт не так при экспериментах — размонтируйте с `/discard`, оригинальный wim держите как копию.
